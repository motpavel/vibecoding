# AI КП

Папка для аналитики, ТЗ и задач по MVP конструктора коммерческих предложений для автосалонов.

## Назначение

Проект: веб-конструктор безопасных коммерческих предложений по продаже автомобилей.

Менеджер автосалона выбирает клиента, автосалон, автомобиль, комплектацию, цвета, условия сделки, может наговорить дополнительный комментарий голосом, получить AI-разбор и AI-текст, проверить предупреждения и сформировать PDF.

Главный принцип: AI не продает автомобиль и не придумывает условия. AI только помогает менеджеру быстрее оформить подтвержденные данные в аккуратный текст.

## Состав папки

- `01-tz.md` - полное техническое задание на MVP.
- `02-epics-and-tasks.md` - декомпозиция работ по этапам.
- `03-issue-templates.md` - готовые тексты issues для GitHub/Codex/Claude Code.

## Критичные ограничения

- OpenAI API key хранится только на backend.
- Нельзя отправлять в AI чувствительные персональные данные клиента.
- AI не имеет права придумывать цену, скидку, ставку, ежемесячный платеж, подарки и наличие автомобиля.
- PDF собирается backend-шаблоном, а не моделью.
- Голосовой ввод используется как ускоритель заполнения и черновик условий, а не как автоматическая отправка КП клиенту.
- Менеджер всегда подтверждает результат перед генерацией PDF.

## Рекомендуемый порядок запуска в работу

1. Прочитать `01-tz.md`.
2. Проверить границы MVP.
3. Пройти `02-epics-and-tasks.md`.
4. Создать GitHub issues по `03-issue-templates.md`.
5. Запускать разработку по правилу: один issue = один PR.

## Стратегия реализации

Не делать сразу CRM, склад, интеграцию с банками и сложную аналитику. Первый MVP должен доказать простую ценность: менеджер может быстро создать красивое, безопасное и проверяемое PDF-КП.
